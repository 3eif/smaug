iMessage Embedder uses Chroma to embed an iMessage history so conversations can be searched, clustered, classified, and visualized.

## Key Features

- Embeds local iMessage history for semantic search.
- Supports clustering, classification, and visual exploration of message data.
- Demonstrates a personal-data retrieval workflow using Chroma.
