Example online marketplace app built with the Next.js App Router and shadcn/ui components.
The bookmark highlights a modern full-stack pattern using parallel and intercepting routes, UploadThing for file uploads, Drizzle ORM, and Clerk authentication.

## Key Features

- Next.js App Router marketplace implementation
- shadcn/ui component usage
- Parallel and intercepting routes
- UploadThing file uploads
- Drizzle ORM data layer
- Clerk authentication
