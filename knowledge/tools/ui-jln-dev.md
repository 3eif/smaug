Open-source TypeScript project that provides more than 10,000 themes for shadcn/ui. It is useful as a theme exploration library for quickly comparing palettes and component styling directions.

## Key Features

- Large catalog of shadcn/ui-compatible themes.
- TypeScript project with a public demo and source repository.
- Useful reference for design-system color exploration.
